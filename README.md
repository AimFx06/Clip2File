# Clip2File

把剪贴板里的截图，**一键存进你当前打开的那个文件夹**。

Windows 小工具 · 免安装 · 单文件 · 25 KB

---

## 解决什么问题

用 `Win + Shift + S` 截图后，图片只在剪贴板里：

- ✅ 能粘到微信、QQ、Word、画图
- ❌ 但按 `Ctrl + V` 到文件夹里 —— 没反应，粘贴菜单是灰的

**原因**：截图工具只往剪贴板写「位图数据」，而资源管理器的粘贴只认「文件列表」格式。
这是 Windows 原生补不上的一步，Clip2File 来补。

## 下载

到 **[Releases](https://github.com/AimFx06/Clip2File/releases/latest)** 页面下载最新的
`Clip2File-vX.Y.Z-win64.zip`，解压后双击 `Clip2File.exe` 就能用。

> 仓库里只放源码，不放编译好的 exe —— 想自己编译就双击 `build.bat`，
> 用的是 Windows 自带的 C# 编译器，不需要装任何东西。

## 怎么用

| 步骤 | 操作 |
| --- | --- |
| 1 | 双击 `Clip2File.exe`，右下角托盘出现蓝色图标 |
| 2 | `Win + Shift + S` 截图 |
| 3 | 打开你要保存到的那个文件夹 |
| 4 | 按 `Ctrl + Alt + V` |

截图立刻以 `截图_20261003_150456.png` 的名字出现在该文件夹里。**全程没有任何弹窗。**

### 图片会存到哪里

按下热键时按这个顺序找目标文件夹：

| 顺序 | 判定 |
| --- | --- |
| ① | 当前前台窗口 —— 资源管理器文件夹窗口在最前面 → 存进它 |
| ② | 最近打开过的文件夹 —— 比如你刚切到浏览器截图，仍然记得上一个文件夹 |
| ③ | 系统里唯一的文件夹窗口 |

都找不到时不会乱存，会在托盘气泡里提示你先打开目标文件夹。

## 主窗口

```
● 正在运行

☐ 开机自动启动
☑ 关闭窗口时留在托盘继续工作

截图后按 Ctrl + Alt + V 保存
图片会存进你当前打开的文件夹
```

上半区是两个开关，下半区是使用说明。没有按钮。

## 更多功能

- **开机自动启动**（可选，默认关闭）—— 勾选后写入「启动」文件夹的一个快捷方式，
  取消勾选即移除。**不写注册表**；程序被移动过位置时还会自动修正快捷方式
- 托盘图标 **双击** = 打开主窗口
- 托盘图标 **右键** = 打开主窗口 / 退出
- 剪贴板里如果是**复制的文件**，按热键会把这些文件复制到目标文件夹
- `Ctrl+Alt+V` 被别的软件占用时，自动降级为 `Ctrl+Alt+X` 或 `Ctrl+Alt+Z`，窗口里会显示实际生效的热键
- 关闭主窗口默认**留在托盘**继续工作（可取消勾选）；托盘右键「退出」才真正结束

## 命令行

```bat
Clip2File.exe --save "D:\某个文件夹"    :: 静默保存一次后退出（适合配合其他工具调用）
Clip2File.exe --help                    :: 查看帮助
Clip2File.exe --version                 :: 查看版本
```

## 系统要求

Windows 10 / 11（系统自带 .NET Framework 4.8）。

免安装、不写注册表。删掉 exe 就等于卸载；
如果开过开机自启，取消勾选或删掉启动文件夹里的 `Clip2File.lnk` 即可。
